## Автоматизация тестирования

Практический проект по написанию и поддержке модульных тестов для Python-кода.

В рамках работы над тестами:

- Организовала тесты по модулям и проверяемым функциям.
- Использую pytest для запуска и организации тестов.
- Изолирую внешние зависимости с помощью моков и `unittest.mock`.
- Вынесла повторяющуюся логику в вспомогательные функции.
- Рефакторю тестовый код, чтобы уменьшать дублирование и упрощать поддержку.
- Проверяю результаты изменений запуском тестов.

**Технологии:** Python, pytest, `unittest.mock`.


from unittest.mock import Mock

import pytest


class ImageClient:
    """Упрощённый клиент для отправки изображений."""

    def __init__(self, base_url, http_client):
        self.base_url = base_url
        self.http_client = http_client

    def upload(self, filename, content):
        return self.http_client.post(
            f"{self.base_url}/files",
            files={"file": (filename, content)},
        )


def test_upload_sends_post_request_to_expected_endpoint():
    http_client = Mock()
    http_client.post.return_value = Mock(
        status_code=201,
        json=Mock(return_value={"id": 42}),
    )

    client = ImageClient(
        base_url="https://example.test/api",
        http_client=http_client,
    )

    client.upload("sample.jpg", b"test-image-content")

    http_client.post.assert_called_once_with(
        "https://example.test/api/files",
        files={"file": ("sample.jpg", b"test-image-content")},
    )
